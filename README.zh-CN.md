# 十二面书房

[English](README.md) · **中文**

翻一下十二面体，就进入一门科目的学习空间；再翻一下小方块，就开始专注计时。

- **八种语言**：英文（默认）、简体中文、繁体中文、日文、韩文、西班牙文、葡萄牙文（巴西）、法文，在“设置 → 语言”里切换。界面、科目（按各国学制调整，比如日文里是“国語”，法文里生物是 SVT）、年级叫法和 AI 的讲解语言都会跟着换。
- **十二面体导航**：每个面是一门科目（语文、数学、英语、物理、化学、生物、历史、地理、编程、艺术、体育、自习）。翻到哪一面，颜色、纸张纹理、字体、待办、笔记和 AI 的讲解风格都跟着换。
- **三种身份**：默认是中学生的十二科。在“设置 → 书架”里可以换成大学生（高数、英语、专业课、论文、考试……）或上班的人（专注、沟通、写作、项目、数据……），每个面的名字都能改成你自己的课程或项目。每日时间轴的建议上限：中学生 2 小时，大学生和上班的人 4 小时。
- **书架与新建十二面体（原型）**：在“全部科目”下拉框或“设置 → 书架”里点“新建”，填学校、院系、专业，选学年，AI 会按学年各生成一个十二面体（一个学年一个），先预览、可以改名，再放上书架。也可以填一个工作类型（比如“产品经理”），生成一个学这份工作的十二面体。把学校的培养方案粘贴进去，AI 只从方案里挑课，结果更准；不粘贴时，生成的是按常见培养方案整理的参考。生成好的存在本机，以后打开不再消耗 token。可以放好几个专业、好几个学年，在书架上随时切换。
- **计时小方块**：每个面是一个时长（5 到 120 分钟），翻到就开始。番茄模式会在专注后自动休息，每 4 个番茄休息更久。
- **今日安排**：每科设今日目标，时间轴显示一天的学习和休息，建议一天不超过 2 小时，超出的部分换颜色显示。
- **问 AI**：每科有不同的讲解风格。你也可以直接让它帮你操作，比如“帮我加个背单词的待办，然后开始 25 分钟”。
- **深度思考**：提问框下面有“深度思考”开关，默认打开，难题想得更周全，但会慢一些、多用一些 token；简单问题可以关掉。生成十二面体和排计划时不思考，更快更省。
- **当下以外的时间轴（2.0 原型）**：点顶部的“未来”，展开一条透视的路。你站在最下面，目标（学习、技能或职业方面）是地平线上缓缓旋转、悬浮着的十二面体。近几周又大又清晰，远到一年之后被压缩到地平线附近，淡而概括——“近处具体、远处模糊”是看出来的，不是读出来的。每个阶段是横在路上的一条色带，点一下看这一段的任务，一键把本周任务放进“今天”的待办，完成任务时目标十二面体的 12 个面会一个个点亮。可以在同一条路上放多个目标（大小不同的十二面体），变化了就重排剩下的路。人生本身（婚姻、家庭、命运……）不放上来，留给未知。看见未来，走向未来。
- **多家 AI 自动切换**：填几家平台的密钥，排在前面的先用。一家额度用完或出错，就自动换下一家。

不用注册账号，也没有服务器。所有数据（待办、笔记、计时记录、密钥）只保存在你自己的浏览器里。

## 怎么用

1. 打开网页，点右上角 **设置**。
2. 选一两家 AI 平台，点“申请密钥”，到平台官网注册并复制 API Key，粘贴回来。
3. 点 **测试**。显示“可以用”就好了。
4. 用箭头调整顺序，常用的、免费的放前面。

各家的免费额度变化很快，下表只是写这个项目时（2026 年 10 月）查到的情况，**请以各平台官方页面为准**：

| 平台 | 默认模型 | 免费情况 |
|---|---|---|
| Claude | claude-haiku-5-5 | 按量付费，小模型很便宜 |
| DeepSeek | deepseek-flash | 新用户赠送 token（已实测可用） |
| 智谱 GLM | glm-4.7-flash | Flash 系列免费 |
| 火山方舟 · 豆包 | doubao-seed-2-0-lite | 每天有免费 token |
| 硅基流动 | Qwen/Qwen2.5-7B-Instruct | 部分小模型免费 |
| Google Gemini | gemini-3.8-flash | 有免费档，按次数限流 |
| OpenRouter | 自己选 | 有带 `:free` 的免费模型 |
| 自定义 | 自己填 | 任何兼容 OpenAI 接口的服务，比如本机的 Ollama |

模型名可以在设置里直接改。平台换了模型名、旧模型下线时，测试会提示“模型名不对”，换一个即可。

### 给家长和老师

- 国内平台注册通常要实名，未成年学生需要家长帮忙申请密钥。
- 每个人用自己的密钥。不要把一个密钥分给很多人用，很快会被限流，也可能违反平台条款。
- 密钥保存在浏览器里。在公用电脑上用完，记得到“设置 → 备份与清除”里清除密钥。

### 换设备

数据只在这台设备上。到“设置 → 备份与清除”里导出备份，在新设备上导入即可。备份里不含密钥。

## 放到网上（GitHub Pages，免费）

1. 在 GitHub 新建一个仓库，比如 `twelve-faces`。
2. 点 **Add file → Upload files**，把这个文件夹里的所有文件拖进去（保持 `css`、`js`、`locales`、`vendor` 文件夹结构），提交。
3. 打开仓库的 **Settings → Pages**，Source 选 **Deploy from a branch**，分支选 `main`、目录选 `/ (root)`，保存。
4. 一两分钟后，页面会出现在 `https://你的用户名.github.io/twelve-faces/`。

也可以不上网：直接双击 `index.html` 在浏览器里打开。

### 意见反馈

放到 GitHub Pages 后，“设置 → 意见反馈”里的按钮会自动打开这个仓库的 Issues 页面，并预先填好使用身份和改过名的面（用户可以删掉）。记得在仓库的 Settings 里保持 Issues 开启。想改用问卷或邮箱，把 `js/settings.js` 里的 `FEEDBACK_URL` 填上即可。

这个网页本身不收集任何使用数据。

## 已知的限制

- **浏览器直连**：这个网页直接从浏览器调用各家 AI 的接口。DeepSeek 已实测可用；Claude 和 OpenRouter 官方明确支持这种用法。其他几家还没实际验证，如果测试显示“连不上（可能断网了，或这家不允许网页直接访问）”，说明这家平台不接受网页直连，请换一家。
- 国内访问时，Google 字体可能加载不到，会自动改用系统字体，不影响使用。
- 3D 需要浏览器支持 WebGL。不支持时会显示科目按钮，功能都一样。

## 文件说明

```
index.html        页面
icon.svg          网页图标（线条十二面体）
css/app.css       样式
js/i18n.js        多语言：代码里只写 key，运行时按当前语言取文案
locales/*.js      语言包：en、zh、zh-TW、ja、ko、es、pt-BR、fr（科目、讲解风格、AI 提示词都在语言包里）
js/profiles.js    三种身份和各自的十二个面（只有结构：key、颜色、纹理）
js/app.js         十二面体、计时、待办、笔记、时间轴、问 AI
js/ai.js          多家 AI 的统一调用和自动切换
js/settings.js    设置页、书架和备份
js/maker.js       新建十二面体（AI 按专业学年或工作类型生成）
js/future.js      当下以外的时间轴：目标和通向未来的透视路
vendor/three.min.js  three.js r128（MIT 许可，见 vendor/three.LICENSE）
```

没有构建步骤，也没有依赖要安装。改完直接刷新页面就能看到效果。

### 加一种语言

1. 复制 `locales/en.js`，改名为比如 `locales/it.js`，把第一行的 `'en'` 改成 `'it'`，再把每个 key 后面的文案翻译掉（`{name}` 这样的占位符保持不动），科目和年级按当地学制调整。
2. 在 `index.html` 里最后一个 `locales/…` 那一行后面，加上 `<script src="locales/it.js"></script>`。

设置里的语言选项会自动出现。缺的 key 会退回英文，并在浏览器控制台里提示。
